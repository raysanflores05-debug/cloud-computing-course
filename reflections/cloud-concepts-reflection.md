# Reflection on Cloud Computing Concepts

Cloud computing has become an important part of my daily life because I regularly use different online services and applications. Three cloud services that I commonly use are Google Drive, Messenger, and Canva. These applications help me store files, communicate with other people, and create digital content using the internet.

Google Drive can be classified as Software as a Service (SaaS) because it provides ready-to-use applications for storing, creating, and managing files online. It uses a Public deployment model because its services are available to many users through the internet. Messenger is also an example of SaaS because it allows users to communicate through an online application without managing the servers or infrastructure behind it. It can be considered a Public cloud service because it is accessible to users through the internet. Canva is another SaaS application because it provides online tools for creating presentations, graphics, and other digital content. It also uses a Public deployment model because users can access the service online.

Git and GitHub are important when working with cloud projects because they help developers manage and track changes in their files and projects. Version control allows users to see previous versions of their work, identify changes, and restore files when mistakes happen. GitHub also makes collaboration easier because team members can work on the same project while keeping track of their contributions. This is especially useful when working with cloud infrastructure because incorrect changes can cause problems. Overall, learning Git and GitHub helps me become more organized and responsible when developing and managing cloud-based projects.
